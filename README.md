# Images

Upload one JPG per day, named `day-01.jpg` ... `day-30.jpg`.

- Size: 1080 x 1350 px (4:5 portrait) for feed posts and carousel covers
- Format: JPG (safest for Instagram). Max about 4 MB for Facebook via Zapier
- Reels need video, not images. Host video elsewhere and use the video action
- Repo must be PUBLIC so Facebook/Instagram can fetch the link
